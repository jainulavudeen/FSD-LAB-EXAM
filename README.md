# Exam Project – Front-End + Node.js/MongoDB

One project, one URL.

| Question | Where |
|---|---|
| Q1 – Online Food Ordering Form (HTML, CSS, JS) | `/` (home page) |
| Q2 – Employee search & salary update (Node.js + MongoDB) | `/employee.html` (UI), `GET /employee/:employeeId`, `PUT /employee/:employeeId` |

## Run locally
```bash
npm install
npm start
```
Open http://localhost:3000 (needs MongoDB locally, or set `MONGO_URI`).

## Deploy
Deployed on Render with MongoDB Atlas. Set the `MONGO_URI` environment variable.
